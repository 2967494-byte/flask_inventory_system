# Быстрое исправление проблем

## Проблема 1: Ошибка генерации токена при /login

### Что исправлено
Обновлен код бота для лучшей обработки ошибок и таймаутов.

### Как применить исправление

**Вариант 1: Используя скрипт (рекомендуется)**
```powershell
.\deploy.ps1
# Выберите опцию 1 (Restart bot only)
```

**Вариант 2: Вручную**
```powershell
docker compose restart bot
```

**Вариант 3: Если Docker не работает**
Проверьте, запущен ли Docker Desktop:
1. Откройте Docker Desktop
2. Дождитесь полной загрузки
3. Попробуйте снова

### Проверка
После перезапуска попробуйте команду `/login` в Telegram боте.

Если ошибка повторяется, проверьте логи:
```powershell
docker compose logs bot
```

## Проблема 2: Дизайн страницы с идеями не обновился

### Что нужно сделать
Пересобрать и перезапустить frontend контейнер.

### Как применить исправление

**Вариант 1: Используя скрипт (рекомендуется)**
```powershell
.\deploy.ps1
# Выберите опцию 2 (Rebuild and restart frontend)
```

**Вариант 2: Вручную**
```powershell
# Пересобрать frontend
docker compose build frontend

# Перезапустить frontend
docker compose restart frontend
```

### Проверка
1. Откройте http://asauda.ru:8002
2. Перейдите в раздел "Идеи"
3. Обновите страницу (Ctrl+F5 для полной перезагрузки)
4. Вы должны увидеть обновленный дизайн

## Полная перезагрузка всех сервисов

Если проблемы сохраняются, выполните полную перезагрузку:

**Используя скрипт:**
```powershell
.\deploy.ps1
# Выберите опцию 3 (Rebuild and restart all services)
```

**Вручную:**
```powershell
docker compose down
docker compose up -d --build
```

Это пересоберет все контейнеры и запустит их заново.

## Просмотр логов

**Все логи:**
```powershell
docker compose logs -f
```

**Логи конкретного сервиса:**
```powershell
docker compose logs -f bot      # Логи бота
docker compose logs -f backend  # Логи API
docker compose logs -f frontend # Логи фронтенда
```

Нажмите Ctrl+C для выхода из просмотра логов.

---

## Если Docker не запускается

1. **Проверьте, запущен ли Docker Desktop**
   - Откройте Docker Desktop
   - Дождитесь, пока статус станет "Running"

2. **Перезапустите Docker Desktop**
   - Закройте Docker Desktop
   - Откройте снова
   - Подождите 1-2 минуты

3. **Проверьте WSL 2 (если используется)**
   ```powershell
   wsl --status
   ```

4. **Если ничего не помогает, перезагрузите компьютер**
