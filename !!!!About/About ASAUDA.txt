# Описание системы ASAUDA (Flask Inventory System)

## 1. Общее описание
**ASAUDA** — это платформа для реализации неиспользуемых складских запасов (неликвидов) между юридическими и физическими лицами. Система построена на базе фреймворка Flask и предоставляет полный цикл функций от регистрации пользователя до заключения сделки (через внутренний чат).

### Стек технологий
- **Backend**: Python (Flask), SQLAlchemy (ORM).
- **Database**: PostgreSQL / SQLite (поддерживается миграция через Flask-Migrate).
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla), Jinja2 Templating.
- **Интеграции**: Telegram Bot (уведомления), Dadata (проверка контрагентов), SMTP (email).

---

## 2. Структура проекта
Проект имеет модульную структуру с использованием Blueprints:

- **Auth (`app/auth.py`)**: Модуль аутентификации.
- **Main (`app/blueprints/main.py`)**: Основной функционал (каталог, товары, профиль).
- **Admin (`app/admin.py`)**: Панель администратора.
- **API (`app/blueprints/api.py`)**: Внутреннее API для фронтенда.
- **Monitoring (`app/blueprints/monitoring.py`)**: Системный мониторинг.

---

## 3. Функциональные возможности

### 👤 3.1. Пользователи и Авторизация
*   **Регистрация**: Создание аккаунта с указанием email, пароля, ИНН, названия компании. Подтверждение капчи.
*   **Авторизация**: Вход по email и паролю.
*   **Профиль**: Редактирование данных компании, контактного лица, описания деятельности.
*   **Восстановление пароля**: Сброс пароля через Email с использованием токена.
*   **Отзывы**: Возможность оставлять отзывы о продавцах и просматривать рейтинг.

### 📦 3.2. Управление товарами (Объявлениями)
*   **Добавление товара**:
    *   Загрузка изображений (drag-and-drop).
    *   Выбор категории (из иерархического списка).
    *   Указание цены (фиксированная, "от", договорная) и наличия НДС.
    *   Указание местоположения (Регион, Город).
*   **Управление статусами**:
    *   *Опубликован* (виден всем).
    *   *Черновик / Не опубликован* (скрыт).
    *   *Архив* (истек срок размещения).
*   **Продление**: Возможность продлить публикацию объявления.
*   **Поиск и Фильтрация**:
    *   Поиск по ключевым словам.
    *   Фильтр по категориям.
    *   Фильтр по локации (Регион / Город).
*   **Избранное**: Добавление товаров в список избранного.

### 💬 3.3. Коммуникация
*   **Система сообщений**: Внутренний чат между покупателем и продавцом.
*   **Привязка к контексту**: Диалог привязывается к конкретному товару.
*   **Вложения**: Отправка файлов и изображений в чате.
*   **Статусы**: Отслеживание статуса "Прочитано".
*   **Служба поддержки**: Форма обратной связи для пользователей.

### 📍 3.4. География и Категории
*   **Категории**: Древовидная структура (Родитель -> Ребенок). Возможность загрузки иконок.
*   **Локации**: База данных регионов и городов РФ. API для динамической подгрузки городов при выборе региона.

### 🛠 3.5. Панель Администратора (`/admin`)
Доступна только пользователям с ролью `admin`.

*   **Управление категориями**:
    *   Создание, редактирование, удаление категорий.
    *   Загрузка структуры категорий из JSON.
    *   Управление изображениями категорий.
*   **Управление пользователями**:
    *   Просмотр списка всех пользователей.
    *   Блокировка/Активация пользователей.
    *   **Имперсонация**: Вход под любым пользователем для отладки ("Войти как").
*   **Управление локациями**:
    *   Добавление/удаление регионов и городов.
    *   Массовая загрузка локаций.
*   **Новости**:
    *   Публикация новостей на сайте.
    *   Редактирование и удаление новостей.
*   **Мониторинг**:
    *   Просмотр системных метрик.
    *   Статистика регистраций и активности.
*   **Настройки баннеров**: Управление рекламными баннерами в сайдбаре.

### 🤖 3.6. Системные функции и Интеграции
*   **Telegram Bot**: Отправка уведомлений об ошибках (500 Internal Server Error) и старте/остановке системы администратору.
*   **Analytics**: Внутренняя система трекинга событий (просмотры, клики по телефону).
*   **File Serving**: Безопасная отдача загруженных файлов через Flask route.
*   **Security**: CSRF защита форм, хэширование паролей, безопасные заголовки.

## 4. Схема Базы Данных (Models)
Основные сущности системы:

1.  `User`: Пользователи системы.
2.  `Product`: Товары/Объявления.
3.  `Category`: Иерархия категорий товаров.
4.  `Region` / `City`: Географические справочники.
5.  `Message`: Сообщения чатов.
6.  `Review`: Отзывы и рейтинги.
7.  `AnalyticsEvent`: Журнал событий для аналитики.
8.  `News`: Новости платформы.
9.  `ContactRequest`: Обращения в поддержку.
